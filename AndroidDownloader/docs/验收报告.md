# Android 0.1.0-alpha02 内测验收报告

日期：2026-10-19（北京时间）。应用 ID：io.feather.videodownloader.android，versionCode 2，最低 Android 10 / API 29，编译及目标 API 37，ARM64。

## 本轮结论

六个平台各两个不同公开视频，共 **12 / 12 条在同一最终 Release APK 中下载通过**。每条都核验实际音视频流和时长、用手机内置 FFmpeg 解码首／中／尾各一段、保存到公共 MediaStore，再使用 Android 媒体读取器及 SHA256 核对保存后的文件。原先失败的抖音分享短链及 TikTok 竖屏样本均已通过。

环境：Android 16 / API 36 ARM64 模拟器，实际 4 KB 页；非计费 Wi-Fi，海外网站使用可访问其内容的网络。所有网站测试为匿名模式。小米 17 Pro Max 本轮未连接，本报告没有将模拟器结果当作真机结果。

最终 APK SHA256：`3db46f408892985ed869ab26e5bd03cf53ab579084909d0709d99315ef48dadb`。已从设备读取已安装的 base.apk，与交付 APK 逐字节哈希核对一致。签名证书与 alpha01 一致，可覆盖升级；APK 不包含签名密钥。

## 本版修复

- 抖音：页面脚本启动前安装观察器；使用限定官网来源、仅主框架可发送的消息桥；匿名服务复用时重置状态，结束或取消后销毁网页并清理匿名数据。
- TikTok：解析官网 embed／普通页数据，支持带语言参数的页面路由键、短链及有限重试；匿名请求只使用临时网站校验状态。竖屏画质按短边计算，576×1024 不再被 720p 上限误拒绝。
- 快手：原接口未返回数据时，正常匿名访问官网并读取公开作品页面的 SSR 数据；严格核对视频编号、公开状态及媒体域名。最终两条样本均实际走通此备用路径，未使用旧缓存下载地址或外部解析服务器。
- 完成核验：生产代码增加 FFprobe 时长和流类型检查，拒绝把 HTTP 200 的 HTML／JSON 验证页当作完成的视频。保留公共保存长度核验和恢复机制。
- 资源约束：普通网页 HTTP 请求有 30 秒累计期限，TikTok／快手备用解析有 45 秒期限和 2 MB 网页上限，解析阶段整体 90 秒；超时和取消会断开活动 HTTP 连接并停止相关原生进程。
