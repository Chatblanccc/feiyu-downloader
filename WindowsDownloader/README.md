# 飞羽下载 Windows 版 0.4.0

适用于 Windows 10 / Windows 11 的 Intel、AMD 64 位电脑。安装包内置视频下载、媒体处理、离线语音识别程序和翻译运行时，无须另外安装 Python、Node.js 或 FFmpeg。Windows on ARM 的本机 ARM64 包尚未提供。

Windows 0.3.2 默认使用「不读取浏览器」。公开抖音链接若直接解析失败，会自动尝试独立的临时匿名网页提取，无须切换登录状态或手动打开视频网站。此过程不会读取 Chrome、Edge 或飞羽保存的登录状态，也不会保存此次网站会话。受限或需要登录、验证的视频仍可能需要你主动选择登录方式。

## 安装与使用

双击 `FeiyuDownload-0.4.0-Windows-x64-Setup.exe`，选择保存程序的位置即可。安装到当前用户，无须修改系统浏览器或替换 Mac 软件。安装包未使用商业代码签名证书，系统显示的发布者可能为未知；请核对随包的 SHA256SUMS.txt。不要关闭系统安全功能。

下载：粘贴链接或整段分享文案，可批量添加。选择画质和保存位置，保留默认的「不读取浏览器」即可尝试下载公开视频；公开抖音链接会在需要时自动尝试临时匿名网页提取。若主动选择的 Chrome/Edge 登录状态因 Windows 加密或占用无法读取，会提示并尝试一次不带登录状态的解析；不会自动读取其他浏览器。

仅当网站要求登录、验证或视频访问受限时，可选择「应用内网站会话」，粘贴视频链接并点击「打开视频网站」。在新窗口中完成网站验证或登录，确认视频可以播放后关闭窗口，再返回解析、下载或手动重试。此模式仅使用飞羽自己保存的网站会话，并按当前视频网站筛选 Cookie，通过临时文件传给下载组件，处理后删除。也可以主动选择 Firefox 或自行导出的 Netscape Cookie 文件。Chrome/Edge 的应用绑定加密不能通过关闭浏览器解决。

任务完成前会核对最终文件。退出后未完成任务保留中断状态，重新打开不会自行继续下载。移除任务仅移除历史记录，不删除已下载的视频。

如首次字幕处理检测到缺少 Microsoft Visual C++ x64 运行库，程序会提供微软官方下载页，由你自行安装后重开；已安装时无需此步骤。运行库不由程序自动安装。

## 检查更新

安装版 0.4.0 起，可在侧栏或「关于飞羽下载」中点击「检查更新」。程序从公开的 GitHub Releases 检查稳定版，显示版本号、完整安装包大小和更新说明。点击「下载更新」后显示进度、速度并允许取消，下载和 SHA512 校验完成后，再由你点击「重启并更新」。更新沿用原有安装标识和数据位置，保留设置、任务历史、已下载视频及语言资源；不需要先卸载旧版。

程序不会在启动时自动检查、下载，也不会在普通退出时自动安装。重启更新前，必须完成或取消下载、字幕、语言资源准备，并关闭应用内网站会话；程序会明确显示阻止原因。接受重启后会暂停接收新任务，先保存记录、关闭组件，然后启动 NSIS 覆盖更新并重新打开软件。源码开发模式和非 Windows 平台不允许安装更新。

发布需要同一稳定版标签下的 `latest.yml`、完整 NSIS `Setup.exe` 和相应 `.blockmap`。仅推送源码、创建草稿或只上传 macOS 包不会形成可用的 Windows 更新。当前发布源固定为 [Chatblanccc/feiyu-downloader](https://github.com/Chatblanccc/feiyu-downloader/releases)，客户端不包含 GitHub 令牌。

当前 electron-updater 固定为 6.8.9，通过 HTTPS 获取公开发布信息，并使用框架内置的 SHA512 核对安装包。现有安装器没有 Authenticode 发布者签名，该完整性检查不能独立证明发布者身份；系统安全提示仍然保留，不应关闭系统安全功能。后续配置正式代码签名时，继续使用框架默认的发布者签名检查。较早的无更新功能版本需要先手动覆盖安装一次 0.4.0 或更新版本。

## 视频翻译与字幕

打开“翻译与字幕”，选择本地视频或已下载视频，自由选择源语言和目标语言。提供中、英、日、韩、法、德、西、俄、葡、意、阿拉伯、印地、泰、越南、印度尼西亚、荷兰、土耳其、乌克兰语。

首次点击“准备语言包”后会下载约 685 MiB 的公开模型，显示进度，可取消。模型保存在本机应用数据目录，之后无需重复下载。源视频、提取的音频和字幕文本不上传至识别或翻译服务。下载模型需要能访问 Hugging Face；网络不可用时会明确失败，可联网后重试。翻译完全使用本机 CPU，翻译需要至少 8 GB 内存且启动时可用内存不少于 3.5 GB，推荐 16 GB，处理速度因电脑而异。翻译独立进程的内存监测上限为 3 GiB，识别为 2 GiB，媒体提取为 768 MiB；Windows 上采用定时采样及终止自有进程树，不能视为内核级硬隔离。

- 仅原文：语音识别后生成原语言字幕，不进行翻译。
- 仅译文 / 原文＋译文：本机生成翻译字幕。
- 仅 SRT：生成字幕文件。
- 可开关字幕：生成带字幕轨的 MKV，保留原视频和声音编码。
- 字幕直接显示在画面中：生成 MP4 和 SRT。字幕无黑色底板，保留细描边；可调 60%–200% 字号、自定义颜色和顶部/居中/底部位置，带预览且记住设置。SRT/可开关字幕的外观由播放器控制。

输入最长 2 小时。烧录视频最长边缩至 1920 像素，保留原声。每项识别/翻译/导出有 30 分钟时限；处理时可取消。识别与翻译会有错误，请检查字幕中的人名、数字和时间点后使用。

## 构建

构建需要 Node.js 24/26 和 Python 3，仅构建环境需要这些工具，使用安装包不需要。

固定版本依赖和上游工具的校验和在 package-lock.json、vendor/win-x64/tools-manifest.json 和 src/subtitles/model-manifest.json 中。

```
npm ci --ignore-scripts
node node_modules/electron/install.js
node scripts/fetch-windows-node-deps.cjs
python scripts/fetch-tools.py
npm test
npm run dist:win
```

打包使用 Electron + NSIS，默认不签名。macOS Apple Silicon 没有 Rosetta 时，需要 ARM 原生 NSIS 编译器，通过 ELECTRON_BUILDER_NSIS_DIR 指向私有 NSIS 工具包；不需要修改系统缓存。源码包包含构建说明及第三方许可。模型按固定提交和 SHA256 校验，无需 API Key。

Windows 0.3.2 已在 Windows 实机通过 74 项自动化测试。主界面保留默认「不读取浏览器」和最佳画质，成功下载一条公开抖音视频（14,705,018 字节），未额外打开可见的网站窗口。独立匿名提取也已确认输出包含视频和音轨，时长约 68.545 秒、分辨率 1080×1920，且未调用已保存的凭据提供方。这些结果仅覆盖本次测试链接，不代表所有网站或受限内容均可下载。本次未测试安装器交互、字幕模型下载及字幕处理；系统编码器、浏览器登录和资源上限仍需按实际使用环境验收。

0.4.0 更新功能新增 11 项注入式测试，本地完整 Windows 源码测试共 86 项通过，覆盖手动检查、重复请求、取消与完成的竞争、校验失败、任务忙碌、重启前状态保存和安装启动错误。macOS 上运行 Electron 验证了实际更新面板、开发模式限制，以及模拟下载进度、取消、任务忙碌与待重启状态；这不代表已在 Windows 执行过一次真实的 GitHub 安装升级。Windows 实机覆盖升级与更新后数据保留仍需验收。
