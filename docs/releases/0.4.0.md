# 飞羽下载 0.4.0

- 新增从软件内主动检查 GitHub 稳定版本更新。
- 用户确认后下载更新包，校验完成后选择重启并更新，无需先卸载旧版本。
- 更新准备保留下载、字幕记录与设置；有工作进行时避免中断安装。
- macOS 使用 Sparkle 验证签名更新包及签名更新列表；Windows 使用 electron-updater/NSIS 完整更新包。
- 保留 Windows 0.3.2 的公开抖音匿名解析、显式网站会话和 User-Agent 修复；修正 iesdouyin 分享链接的会话筛选。

当前发布候选尚无 Apple Developer ID 公证和 Windows Authenticode 签名。首次启用更新功能需覆盖安装一次本版本；旧安装包无法凭空获得检查更新入口。Windows 实机安装升级、Mac 的正式签名与其它机器兼容性需分别验收；单元测试通过不代表这些项目已完成。
