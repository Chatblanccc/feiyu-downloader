# 飞羽下载

原生 macOS 视频下载工具。0.4.1 统一软件内飞羽标志，保留 GitHub 检查更新，并可调整字幕字号、文字颜色和位置，并保留视频翻译、字幕文件和带字幕视频导出功能。

适用于 Apple Silicon（M 系列）Mac。视频下载需要 macOS 13 或更新版本；视频翻译与字幕需要 macOS 26 或更新版本。实际验证环境见交付包的验收报告。

## 视频翻译与字幕

在已完成的下载任务中点击“翻译并添加字幕”，或进入侧栏“翻译与字幕”，通过“已下载”选择视频，也可用“选择视频…”导入本地文件。

从列表中选择“视频中的语言”和“翻译成”，再选择仅原文、仅译文或原文＋译文。仅原文用于生成同语字幕；源语言和目标语言相同也会生成同语字幕。可用语言和翻译方向取决于 macOS 系统支持与本机语言资源，部分组合可能无法处理。

输出方式：

- **仅导出字幕文件**：生成 SRT，供播放器或剪辑软件使用。
- **可开关字幕的视频**：生成 SRT 和带字幕轨的 MP4。播放器中可开关字幕；没有显示时，请打开字幕轨道。视频画面和声音保留原编码。
- **字幕直接显示在画面中**：生成 SRT 和字幕已绘制在画面内的 MP4，便于直接观看和分享。字幕使用白字和细黑描边，背景透明。视频画面会重新编码，最长边限制为 1920 像素；更高分辨率的输入会缩小。

点击“开始生成字幕”后，首次使用所选语言时，Apple 系统可能提示联网下载语音识别或翻译资源，请按系统提示完成准备。字幕功能使用系统能力，无需另填 API Key；语言准备时间受网络和资源大小影响。

选择“字幕直接显示在画面中”时，可在“字幕样式”调整字号（60%–200%）、文字颜色（预设或自定义）及底部、居中、顶部位置，并查看即时预览。字幕保持透明背景与细描边。设置会保存到本机，任务记录也保留当时的样式；“恢复默认”可还原白色、100%、底部。SRT 和可开关字幕的显示样式由播放器控制。

每个视频最长 2 小时。输入文件保持完整，输出保存到单独的任务文件夹，默认位于 `~/Downloads/飞羽下载/字幕`；带字幕视频继续播放原声。生成后可用“打开字幕”和“播放视频”检查识别、翻译、人名、数字及字幕时间，再使用或分享结果。

X 的“未返回可下载视频”与“帖子已删除”会分别提示。某些内容在匿名接口中不可见，需要用户主动从顶部登录状态菜单选择已登录且有权访问的浏览器。应用不会因为解析失败而自动读取登录状态。

## 下载与安装

打开 `飞羽下载-0.4.1-AppleSilicon.dmg`，将“飞羽下载”拖到 Applications（应用程序），再从应用程序中打开。粘贴视频链接或完整分享文案，选择画质与保存文件夹即可下载；默认保存到 `~/Downloads/飞羽下载`。

界面使用 SwiftUI，下载核心使用 Foundation，内置 yt-dlp、Deno、FFmpeg/ffprobe，macOS 系统 WebKit 为特定网站提供临时浏览器解析。

## 本地构建

在项目工作区运行（只在工作区下载依赖，不做全局安装）：

```sh
python3 MacDownloader/scripts/fetch-tools.py
python3 MacDownloader/scripts/build-ffmpeg.py
python3 MacDownloader/scripts/build-app.py
python3 MacDownloader/scripts/package-dmg.py
```

`fetch-tools.py` 使用固定的上游版本与官方校验和；`build-ffmpeg.py` 从官方未修改源代码构建只含所需模块的 LGPL 配置，禁止 GPL、nonfree 与外部编码库。应用打包前复核组件哈希，再逐个本地签名并封存 app。完整构建参数与上游许可随 app 保存在 Resources/Licenses。

## 核心验证

有 Xcode/XCTest 环境可用 `swift test`。本机只有 Command Line Tools，缺少 XCTest 模块，因此同一测试源码提供不依赖 Xcode 的断言入口：

```sh
swiftc -swift-version 5 -D FEATHER_STANDALONE MacDownloader/Sources/DownloadCore/*.swift MacDownloader/Tests/DownloadCoreTests/DownloadCoreTests.swift -o work/download-core-tests
work/download-core-tests
```

打包后可直接验证实际内置工具和下载路径：

```sh
outputs/飞羽下载.app/Contents/MacOS/FeatherApp --smoke-test
outputs/飞羽下载.app/Contents/MacOS/FeatherApp --integration-test 'VIDEO_URL' --destination 'OUTPUT_FOLDER' --quality best
```

诊断入口通过 DownloadCore 的同一解析和下载实现，不依赖终端上另装的下载工具。

## 数据与行为

下载到用户选择的目录，默认 `~/Downloads/飞羽下载`。历史记录保存在本机 Application Support/FeatherDownloader；浏览器会话默认关闭，只有用户主动选择才读取。Cookie 文件以私有临时副本使用，任务结束后删除。

链接解析、下载失败、取消与重试均保留明确状态；完成必须收到结构化最终路径、进程成功退出，并验证非空常规文件。断电或退出后中断的队列不会被伪标成完成。

0.1.1 补充失败后的资源约束：子进程输出和每行数据有硬上限，进度只传必要字段；下载按实际字节增长判断是否卡住，任务超时或超出内存预算时结束整个独立子进程组。预览会先等待旧任务收尾，进度在单槽中合并，封面有下载大小和解码尺寸上限。抖音只允许一个临时浏览器解析会话，禁止媒体自动播放，并限制响应、候选和消息大小。

界面交互避开原生可选择文本与同步状态变化形成的布局循环。下载在独立任务中运行，成功返回后先原子保存私有完成凭据，再更新主界面；重开时只按同一任务、来源及仍匹配的文件大小恢复完成状态。GUI 另有后台心跳保护：主线程持续无响应至少15秒且本体RSS达到512MiB时，写入有界本地诊断、清理已登记的自有下载进程组，并在最多1.8秒内退出。系统WebKit不计入此本体预算。

当前安装包以本地 ad-hoc 签名验证，尚无 Apple Developer ID 签名与公证。公开分发前需要使用开发者账号完成签名、公证与另一台 Mac 的验收。

## 检查更新

从应用菜单、下载设置或“关于”点击“检查更新…”。发现新版本后，Sparkle 会显示更新内容，并在你确认后下载和验证签名；确认安装后等待当前任务结束、保存记录并重启覆盖升级。设置和任务数据保持在原位置。初次启用需先覆盖安装带更新功能的版本；从只读 DMG 运行时请先拖到 Applications。更新包及更新列表均要求 Ed25519 签名；本地更新签名不等同于 Apple Developer ID 签名与公证。详见 [发布流程](../docs/UPDATES.md)。
